# Seeds

Starting patterns for [pattern-language](../SKILL.md), each one file in the [pattern format](../SKILL.md#what-a-pattern-is). They have worked in other projects and are offered to a new project when it meets the problem they solve.

A seed is never in force on its own. Talk it through with the human, and if they choose it, copy its file into the project's `pattern-language/`, adapt it to the project, and set its status to `trial`.
