# Philosophy

Skills that shape how an agent thinks about its work, rather than prescribing a specific practice. Each one stands alone.

- **[pattern-language](./pattern-language/SKILL.md)**: How to grow, use and review a project's pattern language together with the human developer, so that standards and intent outlive any one agent session. Patterns live in a `pattern-language/` folder, one file each; they are discussed before they are written, trialled before they are accepted, and deprecated when the project moves on, with exceptions as evidence and check-ins with the human.
  - **[seeds](./pattern-language/seeds/README.md)**: Starting patterns to offer a new project.
