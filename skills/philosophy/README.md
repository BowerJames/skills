# Philosophy

Skills that shape how an agent thinks about its work, rather than prescribing a specific practice. Each one stands alone.

- **[pattern-language](./pattern-language/SKILL.md)**: A living pattern language for agent-written code that a human must still navigate: strict at the skeleton, free in the flesh. It covers a change protocol that grows code instead of grafting onto it, exceptions as evidence, structural reports and calibration check-ins with the human, and patterns that are proposed, revised and retired from experience.
  - **[PATTERNS](./pattern-language/PATTERNS.md)**: The seed patterns, with confidence ratings and how they look in Python, TypeScript, Go and Rust.
  - **[MEASURING](./pattern-language/MEASURING.md)**: Signals and fresh-agent evaluations that measure findability and changeability without blocking growth.
