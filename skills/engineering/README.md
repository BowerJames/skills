# Engineering

Skills I use daily for code work.

- **[codebase-design](./codebase-design/SKILL.md)**: Shared vocabulary for designing deep modules: small interfaces, clean seams, testable through the interface.
- **[dependency-injection](./dependency-injection/SKILL.md)**: Wiring modules together: code against interfaces, declare seams at construction.
- **[factory-pattern](./factory-pattern/SKILL.md)**: Construction wrapped behind an interface: return the interface, bind runtime data to root-chosen adapters, factories wire rather than work, and earn their place only when construction varies.
